# E4/H5: заранее закреплённая процедура

Применяется к F1/DENSE и F2/DENSE, N=100000, seed=101, генератор версии 2.
Используются исходные фиксированные назначения и сроки. Ранжирование не выбирается
по результатам оценочных сценариев.

Для каждого из 200 станков выполняются одинаковые 15 одиночных отказов:
начало 10/30/50/70/90% C0, длительность 5/10/20% C0. Границы округляются однократно
до секунды по floor(x+0,5). Полные сроки должны быть известны при DIAGNOSTIC 10D.
R — средняя задержка, делённая на C0; F — число срывов D=1,10C0. Сравнение сумм
целочисленных задержек точное. T — первые три по убыванию R, F и возрастанию ID;
B — три оставшихся по возрастанию R, F и ID. Списки и хеш фиксируются до оценки.

Сравниваются исходная конфигурация и шесть увеличений скорости одного станка на
10%. Каждое вмешательство имеет одинаковый бюджет и не меняет число одновременных
операций. Срок D, исходные s0, материал и отказные траектории общие.

Для постоянной скорости 1,10 применяется точное целочисленное преобразование
времени: все исходные моменты умножаются на 11; работа на ускоренном станке
умножается на 10, работа остальных — на 11. Новая единица времени равна 1/11
исходного тика. При preempt-resume и постоянной скорости это эквивалентно p/1,10,
включая прерывания отказами. Округления длительности операции нет. Преобразование
не применяется к меняющейся внутри обработки скорости E1X.

Ранжирование и 1000 оценочных записей проверяются независимыми DAG и DES. Это
проверка полезности ранжирования на точной модели; времена этих расчётов не входят
в H3 и не доказывают преимущество TSFG. Для TSFG требуется самостоятельный допуск
на преобразованном входе и отдельно раскрывается объём реально выполненных проверок.

Оценочные отказы имеют purpose h5_evaluation: интервалы работы каждого станка
экспоненциальны со средним 10D, ремонт равномерен [0,01D;0,03D]. Процессы независимы;
все интервалы готовятся заранее до 10D. Границы округляются до секунды один раз,
ремонт длится не менее секунды. Дополнительная общая причина — отдельная серия,
пуассоновские события со средним 2D на пяти заранее выбранных станках группы 0,
длительность ремонта 0,02D. Она не подменяет основной критерий H5.

В записи сохраняются семь бинарных исходов. e_T — среднее трёх улучшений на T;
d — e_T минус среднее улучшение на B. Для обоих средних строятся парные percentile
bootstrap-интервалы: 10000 повторов по 1000 цельных сценарных записей, quantile linear,
PCG64 с purpose h5_bootstrap по общей схеме seed. SUPPORTED требует строго
положительных нижних границ обоих интервалов и всех корректных завершённых записей.
Иначе NOT_SUPPORTED или INSUFFICIENT_COMPLETED. Семейства не объединяются.

Для доли успеха каждой конфигурации публикуется интервал Уилсона 95%. Это вероятность
в исследовательском профиле отказов, а не оценка эксплуатационного риска предприятия.
Резервный станок, переназначение, транспорт и переналадка не подменяют основной
критерий увеличения скорости; их наличие и отсутствие раскрываются отдельно.
