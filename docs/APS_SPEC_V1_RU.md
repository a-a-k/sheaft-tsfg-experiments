# SHEAFT-LIST-v1 / APS-BASIC

Протокол кампании: Sheaft_Execution_Instructions_v2_2_RU.md. Алгоритм перенесён
из `experiments/scale_data.py:schedule()` снимка
`0ff8dafe10331aa574b23a32ef611f3a6502a909` без изменения переходов.
Генератор прежних опытов импортирует тот же модуль `planning/list_v1.py`.
Глобальный выбор: минимум `(start,end,job,id,machine)` среди готовых операций
и их допустимых назначений. Это эвристика построения расписания.

Вход `APS-BASIC-catalog-v1` — UTF-8 JSONL. Заголовок содержит schema,
machines, tick_unit. Строки `C,id,[[machine,work],…]` задают общий каталог;
строки `O,id,job,release,[predecessors],catalog_id` задают операции. Последняя
строка END содержит размеры и task_sha256. Назначения, выбранная работа,
плановые времена и очереди отсутствуют. Повторные ссылки используют один
объект каталога; планировщик его не изменяет. Каталог может чередоваться
с операциями, ссылка всегда направлена на ранее объявленную запись.

Каноническое содержимое для task_sha256:
`{"tick_unit":…, "machines":…, "operations":[…]}` без пробелов.
Ключи операции строго id,job,release,predecessors,alternatives; ключи
альтернативы machine,work. Операции упорядочены по id, зависимости по id,
альтернативы по machine. Времена целые. Идентификатор набора, seed,
каталожные индексы и родительские хеши не входят в содержательный хеш.
Файловый SHA-256 фиксируется отдельно.

Выход содержит заголовок, все строки `O,id,machine,start,end`, затем
`Q,machine,[operation_ids]`. Все строки закрываются до конца T_total.
T_total начинается перед созданием измерительного процесса; включает
загрузку Python/модуля, чтение, алгоритм и полный вывод. Фазы чтения,
планирования, записи и запуска публикуются отдельно. Внешняя валидация
не входит в это время и имеет собственный показатель. Процесс не порождает
дочерних вычислителей. Память — его VmHWM после exec; отдельный контроль
проверяет этот счётчик на известных выделениях.

Проверки: независимый полный перебор naive_schedule на малых случаях,
физические ограничения расписания и исполнение DAG-REF. Качество: LB по
минимальным длительностям технологических путей с поступлениями, общей работе
и обязательной работе заранее заданных технологических групп. Для M=200
группы равны [0,19],…,[180,199]. Публикуются состав групп, правило
включения, число операций, хеш их id и сумма минимальной работы. Для Mk01
дополнительно используется сохранённый оптимум 40 единиц; новый поиск не
запускается. Совпадение со старым расписанием не считается независимой
оценкой качества.

Матрица, допуск миллиона, лимиты и трактовка рыночного сравнения следуют §3
инструкции 2.2. Результаты первой миллионной пары относятся к указанным
входам и одному повтору. Число 2700/T_total является отношением опубликованного
времени BFG к нашему измерению при разных, раскрытых условиях испытаний.
